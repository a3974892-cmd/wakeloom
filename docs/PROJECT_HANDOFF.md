# Wakeloom 项目维护说明

Wakeloom 是按需使用 Colab GPU 的桌面工作台，提供 ComfyUI 图片/视频工作流和模型对话。Windows 使用 WebView2；实验性 Linux 版本在默认浏览器打开同一工作台。

## 当前版本

2026-11-08：用户授权将测试版界面与诊断改动作为 **v1.21.4** 发布，并整理仓库首页。源码准备已完成；发布成功状态须核对 GitHub Actions、Release 与自动更新清单，不能只看源码版本号。

本轮包含系统字体和卡片留白调整、原创 W 标志、图标导航、API 设置内边距修正、持久化诊断日志和本地引导步骤日志/有限重试。此前测试版的聊天附件、批量技能和数据兼容行为保持。Linux 构建仍属实验性，真实桌面与 Colab 流程需实机验收。

## 仓库结构

- `app/`：Go module、程序代码和测试；维护命令在该目录执行。
- `app/ui/`：内嵌网页界面；`refinement.css` 为界面细化样式，`diagnostics.js` 为日志页。
- `app/kit/`：上传到 Colab 的启动套件与内置配置。
- `app/gateway/`：网关补丁、生成器及兼容性测试。
- `scripts/`：Linux 构建和隔离启动检查。
- `.github/workflows/`：自动检查与发布。
- `docs/`：用户指南及公开维护记录。私人聊天、凭据和用户部署记录不属于仓库内容。

## 维护约定

先读根目录 [AGENTS.md](../AGENTS.md)、[CLAUDE.md](../CLAUDE.md) 和 [ROADMAP.md](ROADMAP.md)。变更必须区分源码实现、模拟测试、正式发布与真实部署；本机测试通过不等于云端网络故障已解决。

保持旧数据目录迁移、`CKWB_` 环境变量、模块名和模板/草稿/聊天/附件/技能兼容性。本地直连与 VPS 网关是独立连接方式，不能因更新桌面程序自动修改网关或停止运行中的 GPU。

启动套件的生成规则见 CLAUDE.md。修改 `app/gateway/src/edits.py` 后，重新生成补丁并同步内嵌 kit；禁止只修改生成物。网关正常运行时不要求重复部署补丁。

诊断日志写盘前过滤常见凭据，轮换约 6 MB，显示/导出最近 3000 条。不记录请求正文，不附带配置、聊天或附件文件；网关事件只在软件连接期间收集。分享前可预览检查。

## 验证与发布

目录整理后的 Windows 全量 Go 测试通过；模型、导入、视觉和引导的 28 项 Python 检查通过。正式候选 exe 的隔离浏览器检查覆盖浅深色/窄窗口、日志复制/导出/持久化、旧对话迁移、长代码、附件、技能和工作流匹配，均通过。这些检查不启动真实 GPU。

发布流程从 `app/update.go` 读取版本，目前仅发布 Windows exe、网关附件和 Windows 更新清单。用户要求 Linux 等实机测试后再发布；Linux 源码和独立检查保留，不自动发布包或清单。发布后核对标签源码、Release 附件、实际下载的大小与 SHA-256、`releases/latest` 指向，再记录完成状态。不得把未验证的真实 Colab 启动或视觉推理描述成已验收。
