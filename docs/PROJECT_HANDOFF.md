# Wakeloom 项目维护说明

Wakeloom 是按需使用 Colab GPU 的桌面工作台，提供 ComfyUI 图片/视频工作流和模型对话。Windows 使用 WebView2；实验性 Linux 版本在默认浏览器打开同一工作台。

## 仓库结构

- `app/`：Go module、程序代码和测试；维护命令在该目录执行。

- `scripts/`：Linux 构建和隔离启动检查。
- `.github/workflows/`：自动检查与发布。
- `docs/`：用户指南及公开维护记录。私人聊天、凭据和用户部署记录不属于仓库内容。
