# Wakeloom 待办与验收清单

## v1.21.4 发布范围

- 细化字体、卡片间距、浅深色与窄窗口布局，新增原创 W 标志和图标导航。
- 修正大模型 API / H3 指南区域内边距及长路径导致的横向溢出。
- 新增诊断日志的本机持久化、搜索、级别筛选、预览、复制和 TXT 导出；过滤常见凭据。
- 本地启动使用具名步骤日志、有限重试、超时和固定官方下载包校验。
- Linux 源码保留供本地测试；按用户要求暂不发布 Linux 下载和更新清单。
- 将源码与资源集中到 `app/`，同步测试、构建和发布路径，减少仓库首页文件。

## 已完成的本机验证

- Windows 全量 Go 测试与启动套件 Python 兼容性检查。
- 正式候选 exe 的浅深色和窄窗口显示。
- 日志捕获、脱敏、剪贴板复制、预览、文件导出和重启保留。
- 长代码、旧对话迁移、附件、技能、图片能力保护和工作流配置匹配。
- 模拟测试未启动或停止真实 GPU。

- 持续观察不同网络条件下的 Colab 启动。官方源持续超时仍可能导致失败，重试不保证每次成功。
