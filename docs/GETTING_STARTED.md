# 新手指南

第一次用 Wakeloom（唤织）？跟着这一页，从下载到生成第一张图大约 15 分钟，其中一半时间是等 GPU 开机。

软件第一次打开时会自动弹出引导，步骤和这一页一一对应。关掉后可以从右上角的「?」→「新手引导」或「设置 → 软件更新 → 重新运行新手引导」再打开。

---

## 1. 准备什么

| | 说明 |
|---|---|
| Windows 10 / 11 | 需要系统自带的 WebView2（Windows 11 和新版 Windows 10 都有） |
| Google 账号 + Colab 付费算力（CU） | Colab Pro / Pro+ 订阅，或[按量购买](https://colab.research.google.com/signup)的计算单元。免费版只有 T4，跑不了大模型。[什么是 CU？](https://research.google.com/colaboratory/faq.html#compute-units) |
| 网络 | 要能访问 Google、Hugging Face、GitHub。国内需要开代理；软件会自动走系统代理（Clash、v2rayN 的「系统代理」模式） |

## 2. 下载和第一次运行

1. 到 [Releases](../../../releases/latest) 下载 `Wakeloom-x.y.z.exe`。
2. 双击运行。软件没有代码签名，Windows 可能弹出「Windows 已保护你的电脑」（SmartScreen）：
   - 点 **更多信息**；
   - 再点 **仍要运行**。

   ![SmartScreen：更多信息 → 仍要运行](img/smartscreen.png)

3. 想确认文件没被篡改，可以核对 SHA-256（Release 页的 `latest.json` 里有 `sha256`）。在下载目录打开 PowerShell：

   ```powershell
   Get-FileHash .\Wakeloom-1.21.0.exe -Algorithm SHA256
   ```

   或者用命令提示符：`certutil -hashfile Wakeloom-1.21.0.exe SHA256`。两边的值应该完全一样。

## 3. 最简单的方式：三步启动 Colab

引导默认走这条路，不需要服务器，也不用填表。

1. 点 **用 Google 账号开始**。软件会切到「本地模式」，并在浏览器里打开 Google 授权页。
2. 在浏览器里登录、点「允许」，页面会显示一串授权码，点旁边的「复制」。回到软件，按钮会变成 **检测到授权码 · 一键登录**，点它。读不到剪贴板时，展开「手动粘贴」按 Ctrl+V。

   ![第 2 步：登录 Google](img/step2.png)

3. 登录后会显示 CU 余额和推荐组合「RealVisXL 生图 · L4」。点 **启动 Colab**。

   ![第 3 步：一键开机](img/step3.png)

软件会跳到「AI」页的生图面板，并填好一个示例提示词。右下角的小窗显示开机进度：第一次要下载约 7 GB 模型，大约 5～8 分钟。就绪后点 **生成**，几十秒就能看到第一张图。

> 本地模式是实验功能：它用的是 Colab 的非公开接口和 Google Cloud SDK 的公开登录客户端，接口可能随时变化，也有账号被限制的风险。长期稳定使用推荐网关模式。

## 4. 我有自己的网关

已经在 VPS 上部署了 [comfy-colab-kit](https://github.com/FireTable/comfy-colab-kit) 网关的话，在欢迎页点「我有自己的网关 →」，按完整步骤走：

1. **检查网络**：逐项检测 Google、Colab、Hugging Face、GitHub，显示耗时和当前代理。
2. **选择连接方式**：选「网关模式」。
3. **填写网关**：网关地址、Agent 令牌（网关网页右上角「复制 AI Agent 接入指令」里，或 VPS 上的 `secrets/agent_token`），网关在 Cloudflare Access 后面时再填服务令牌。点「测试连接」，成功后会显示网关上的启动配置数量。
4. 网关要打补丁才支持选 GPU、AI 页和添加模型，见 [gateway/README.md](../app/gateway/README.md)。

![第 4 步：连接网关](img/step4-gateway.png)

## 5. 基本设置

- **结果保存位置**：默认「桌面\生成视频」，生成的文件会自动下载到这里。
- **空闲自动停机**：本地模式默认 30 分钟没人用就停机。GPU 开着就一直扣 CU，这一项就是为了省 CU。
- **大模型 API**（「AI 写提示词」用）：可以跳过，以后在「设置 → 大模型 API」里添加。

## 6. 怎么省 CU

- **用完就点「停止」**。GPU 开着就按小时扣费，哪怕什么都没做。
- 选**够用的最小 GPU**：生图（SDXL）用 L4 就够；大语言模型、Chroma 这类大模型才需要 G4。唤醒按钮旁边会显示「预计每小时约 X CU」：用过一次后按 Colab 实际报的值显示，之前是估计值。
- 打开「设置 → 任务 → 队列全部完成 3 分钟后自动停止 GPU」。
- 本地模式把「闲置自动停机」设短一点；网关模式在网关的 `.env` 里设置。
- 先用「低清试生成」看效果，满意再出高清。

## 7. 常见问题

**申请不到 GPU / 一直在「分配机器」**
Colab 高峰期可能暂时没有空闲的 GPU。换一个型号（比如 G4 换 L4），或过几分钟再试。确认 CU 余额大于 0。

**网络不通（检查网络里有 ✗）**
打开代理软件的「系统代理」模式；或在「设置 → 网关连接 → 网络代理」里填代理地址，例如 `http://127.0.0.1:7890`（按你代理软件的端口）。只有 Hugging Face 不通时，「添加模型」用不了，但开机下载模型是在 Colab 上进行的，不受影响。

**H100 没有空闲**
H100 经常被占满。大多数模型用 G4（96 GB 显存）就够，而且更容易申请到。

**显存不够（out of memory）**
换更大的 GPU（L4 → G4），或者换更小的模型 / 量化版本（比如 Q8_0 换 Q4_K_M），或者把生图尺寸调小。「添加模型」会按「文件大小 × 1.2」估算显存，超过 96 GB 的模型不能保存。

**模型下载完成，随后提示 Ollama install failed / HTTP 504**
这是运行环境安装包的下载失败，发生在 Ollama 启动前。1.21.3 使用官方资产 API 及其他官方入口回退、固定版本完整校验并实时显示进度。本地模式运行1.21.3 正式版 exe，下次唤醒使用新版下载流程；网关模式可只应用 `gate-ollama-download.py`，见 [网关说明](../app/gateway/README.md)。之前的 bootstrap 错误发生在其他步骤，不能据此认定已一并解决。

**工作流没了**
Colab 每次开机都是新机器。软件默认会把 ComfyUI 里保存的工作流和设置备份到电脑上，下次开机自动传回去（控制台「工作流备份」一行）。

## 8. AI 对话的附件与技能

在 AI 对话输入框上方点「＋ 文件 / 压缩包」或「文件夹」，也可以把文件拖到聊天区，或在输入框粘贴截图。添加后先显示文件名与读取结果，点击「发送」才会把内容交给 GPU 上的模型。文档读取文字，支持 PDF、DOCX、TXT/Markdown/代码；扫描 PDF 请先识别文字。压缩包支持 ZIP，RAR/7Z 请先解压，旧 DOC 请另存为 DOCX。

附件已取消原来的单文件 10 MB、合计 31 MB 和 100 文件限制。文件夹分批读取，可取消，已完成文件会保留；完整文字缓存在本机，发送时按问题和文件名选择片段，回复中的「本次附件」显示实际带入的文件、字数及位置。一次模型请求的文字容量仍为 16000 字，不能把保存成功当作模型已读完全部内容。图片支持 PNG/JPG/GIF（GIF 使用首帧），发送前会核对当前模型是否支持图片理解。

需要看图时，内置 Qwen3.8 27B 有两种方式。**本地模式**中，文字模型已经就绪时，在 AI 页点「启用看图 → 下载并启用」，补装约 0.94 GB 的匹配组件，在当前 Colab 会话中检查图片推理，成功后选择视觉模型；原文字模型文件和 GPU 会话保留。安装期间暂停聊天，完成后原来添加的图片可继续发送。也可在下次唤醒直接选「Qwen3.8 27B · Q8_0 对话与看图」。

**网关模式**中，点「启用看图」下载更新包，将文件放在 VPS 的同一目录，运行 `python3 enable-vision-on-vps.py /opt/comfy-colab-kit`（替换实际安装目录）。它通过网关已有 Colab 登录连接正在运行的 VM，保持网关/GPU 会话运行。需要后续新会话的独立看图配置时，再在当前会话结束后应用配套 `gate-ai.py` 启动补丁。安装脚本仅匹配内置 Q8_0 权重；其他模型需使用对应视觉配置。真实 GPU 部署与效果仍须核对，测试界面通过不代表远端已经安装。

点聊天工具栏「技能」，可以安装 SKILL.md、技能文件夹或 ZIP，也能粘贴公开 GitHub 仓库或技能目录链接。仓库包含多个技能时，可多选、「全选筛选结果」或点「安装全部 N 个」，显示逐项进度；默认跳过已安装项目，并可只重试失败项。同名不同目录的技能分别保存。已安装列表可以搜索。

使用有两种方式：勾选技能让它在当前模型的后续消息固定启用；或者不勾选，直接在聊天中写「请使用 reverse-skill-router 技能分析……」临时按名称调用。下一条消息生效，不用重启 GPU。回复中的「本次技能」显示实际带入的指令和参考。安装全部不会自动启用全部技能，一次最多固定启用和临时指定合计 8 个，并受模型文字容量约束。可查看内容、确认替换或卸载。

技能包安装不受聊天容量限制：每次可保存最多 8 MB 文字，压缩包请求最多 32 MB，最多 2000 个文件、256 个技能候选；过大的资源、二进制及无法读取的内容会明确列为未导入。聊天自动保留近期的完整问答，为附件预留空间；过长的技能主说明和手选参考按问题选段，显示节选及未带入项目。较早聊天、全部技能和附件仍保存在本机，不会因本次整理而删除。回复中的「本次技能」和上下文说明可核对实际内容；无需因为累计历史超过 16000 字反复新建对话。

附带脚本不会自动执行，需要浏览器、终端、MCP 或其他外部工具的步骤不能仅靠安装技能完成。脚本、测试与日志可作为手动参考文字查看，不会自动作为普通任务的参考资料带入。

对话、附件和技能都保存在本机数据目录，重启后可继续使用；本次选中的文字和图片会在发送时传给当前连接的模型。设置页面可查看 PDF 组件许可。

## 9. 出现异常时分享诊断日志（1.21.4 起）

左侧点「日志」，再点「复制诊断日志」粘贴给维护者；也可以「导出 .txt」发送文件。支持按错误级别筛选和搜索；复制、预览和导出包含最近全部级别的日志，不受当前筛选影响，便于保留故障前后的过程。

日志包含软件版本、系统、时间、启动过程和错误，自动保存在本机，关闭重开仍保留。最多轮换保存约 6 MB，页面显示和导出最近 3000 条；网关日志只在 Wakeloom 连接期间收集，无法补回此前未记录的过程。没有自动上传日志。

常见密钥、令牌、邮箱和用户目录会被过滤，不附带配置、聊天或附件文件；分享前可以点「预览」检查。若提示无法保存日志，先检查本机数据目录的写入权限和磁盘空间。
